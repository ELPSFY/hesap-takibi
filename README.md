# Hesabım

Mobil uyumlu, tarayıcı tabanlı kişisel gelir-gider takip uygulaması.

## Çalıştırma

1. Reponun sayfasında `Code` > `Download ZIP` ile indir.
2. ZIP'ten çıkar.
3. `index.html` dosyasını tarayıcıda aç.

## Özellikler

- Gelir/gider takibi
- Kategori bazlı aylık limitler
- Planlanan ödemeler
- Tekrarlayan gelir ve giderler
- Birikim hedefleri
- 7 günlük harcama grafiği
- JSON yedekleme ve geri yükleme
- Basit PIN ekran kilidi

Veriler tarayıcının `localStorage` alanında saklanır.
